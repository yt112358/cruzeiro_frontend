## 🧐 Sobre o Projeto

O **Cruzeiro Frontend** é a camada de interface e experiência do usuário (UI/UX) da plataforma Cruzeiro. O projeto foi projetado para ser responsivo, de alto desempenho e fácil de integrar com serviços de backend.

---

## ✨ Funcionalidades

- 📱 **Design Responsivo:** Adaptado para dispositivos móveis, tablets e desktops.
- ⚡ **Alta Performance:** Carregamento otimizado de páginas e componentes.
- 🎨 **Interface Intuitiva:** Componentes estilizados focados na experiência do usuário.
